# 办案期限计算器 · case-deadline-calc

给基层办案民警用的**刑事案件 / 治安案件法定办理期限推算**小工具。命令行一条命令，直接给出各节点的到期日，并把**法条依据**一起打出来。

> ⚠️ 本工具输出为参考推算，不构成法律意见。具体以现行有效法条、司法解释与本单位规定为准。节假日顺延、异地羁押、重新计算等特殊情形，请按本单位规定处理。

## 为什么做这个

办案期限是硬约束：拘留 3/7/30、延长 1–4 日、检察院 7 日审查、取保 12 个月、办案期限 30+30×2、上诉 10 日……
手工算容易出差错，尤其遇到跨月、延长叠加、多种强制措施并存。

这个工具把规则**写成 JSON**，算出来的每个日期都附法条来源，方便复核与写进卷宗说明。

## 用法

```bash
# 刑事拘留（一般 3 日，含延长）
node calc.mjs 刑事 --拘留 2026-11-01 --延长 1

# 治安案件办案期限（立案起算，延长 1 次）
node calc.mjs 治安 --立案 2026-11-01 --延长 1

# 取保候审 12 个月 / 监视居住 6 个月
node calc.mjs 取保 --起算 2026-11-01
node calc.mjs 取保 --起算 2026-11-01 --监视居住

# 一审审限
node calc.mjs 审限 --受理 2026-11-01 --延长 1
```

输出示例：

```
刑事拘留起算：2026-11-01
拘留期限（一般+延长，7日）：至 2026-11-08
　依据：《刑事诉讼法》第91条（特殊情况可延长1至4日）
提请批捕后，检察院审查：7日内 → 最迟 2026-11-15
```

## 规则从哪来

全部写在 [`rules.json`](./rules.json)，每条都带 `依据` 字段。改规则不用改代码。

⚠️ **治安案件适用《治安管理处罚法》2025 修订版（2026-01-01 施行，共 144 条）**，条文号与旧版差异很大，旧版条文号不可用。

## 覆盖范围

| 案件 | 已覆盖 |
|---|---|
| 刑事 | 传唤拘传、刑事拘留（含延长与检察院审查）、逮捕后侦查羁押、取保候审、监视居住、审查起诉、一审审限、上诉抗诉期 |
| 治安 | 传唤、办案期限（含两次延长）、行政拘留执行、复议诉讼期限 |
